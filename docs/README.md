# Building the docs

The published site at <https://emmo-repo.github.io/domain-electrochemistry/> is built and deployed automatically by `.github/workflows/docs.yml` on every push to `master`. You never deploy manually.

To build locally:

```sh
uv sync --extra docs
uv run sphinx-build -n -b html docs docs/_build/html
```

Notes:

- `docs/electrochemistry.rst` (the class index) is generated by CI from the ontology sources with `python .github/scripts/ontology_toolkit.py --generate-rst`. A local build renders whatever was last committed, which is usually what you want.
- Notebooks are never executed at build time (`nbsphinx_execute = 'never'`); commit their outputs.
- The Sphinx warning count is tracked against `docs/sphinx-warning-baseline.txt` by a non-blocking CI job. If your change lowers the count, update the baseline to lock in the gain.
- Ontology terms used in doc examples are linted against `context/context.json` by `tests/test_docs_terms.py`.
